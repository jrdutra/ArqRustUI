# Créditos dos ícones de redes sociais

Os arquivos listados em assets/icons/social/ORIGEM.md vieram do pacote fornecido
`arqrustui-social-icons-bevel-3d.zip`. Arte aplicável baseada em Font Awesome Free,
Fonticons, Inc., Copyright 2024; ícones sob CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/
https://fontawesome.com/license/free

O pacote recebido acrescenta bisel, extrusão, gradientes e cores aos desenhos de origem.
A integração preservou ICO, PNG e SVG byte a byte; alguns nomes locais foram
normalizados para manter a API existente. As marcas pertencem aos respectivos titulares.
O código Rust próprio continua sob MIT. O texto recebido, incluindo suas seções de
licenças para fontes e código, está em assets/icons/social/FONT_AWESOME_LICENSE.txt; somente arte gráfica
foi incorporada, sem fontes, JavaScript ou implementação de terceiros.
